# Basic Physics Experiments

This repo contains high score (\>=99) lab reports and data from

              **SUSTech Basic Physics Experiments Course**

There are 3 branches, each contains one pdf report file and its original
tmu file.

-   杨氏模量：测量铁丝的杨氏模量

-   线性非线性：线性与非线性元件的伏安特性曲线（发光二极管）

-   透镜参数：测量光学透镜参数
